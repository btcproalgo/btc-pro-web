4

Configura tu capital y tu objetivo de Take Profit

Cada usuario debe elegir su propio nivel de riesgo. Esta sección explica la referencia utilizada para BTC PRO.

Importante: no copies automáticamente la configuración de capital de otra persona.

Referencia de capital utilizada en BTC PRO

Como referencia de configuración, puedes utilizar una relación aproximada de 10 a 1 entre tu capital disponible y tu objetivo de Take Profit.

Ejemplo: si quieres configurar un objetivo de 100 USDT por Take Profit, la referencia sería utilizar aproximadamente 1,000 USDT de capital.

Capital de referencia Objetivo TP de referencia Relación
1,000 USDT 100 USDT 10 : 1
2,000 USDT 200 USDT 10 : 1
3,000 USDT 300 USDT 10 : 1
5,000 USDT 500 USDT 10 : 1
10,000 USDT 1,000 USDT 10 : 1

¿Qué debes cambiar dentro de BTC PRO?

✓
Take Profit %

Mantén el Take Profit porcentual de la estrategia en 0.66%.

✓
LIVE - Take Profit objetivo (USDT)

Aquí escribes el objetivo monetario elegido según tu capital y riesgo.

Ejemplo: capital 1,000 USDT → objetivo 100 USDT.

✓
Paso de cantidad BTC

Mantén el paso en 0.001.

También debes revisar WunderTrading

Si aumentas tu objetivo de Take Profit, BTC PRO puede necesitar enviar una posición de mayor valor.

El campo Max Capital de WunderTrading debe ser suficiente para permitir la orden configurada.

No copies el Max Capital de otra persona. Debe adaptarse a tu propia configuración.

5

Prepara Binance Futures

Configura correctamente el entorno donde se ejecutarán las operaciones.

✓
Entra a Futures USDⓈ-M

Desde Binance abre la sección de futuros denominados en USDT.

✓
Selecciona BTCUSDT Perpetuo

BTC PRO utiliza BTCUSDT Perpetual para su automatización.

✓
Modo de margen: Cruzado

En la configuración utilizada por BTC PRO selecciona Cross / Cruzado.

✓
Leverage: 100x

La configuración del Signal Bot utilizada en esta guía trabaja con 100x.

✓
Verifica tu saldo de Futures

Confirma que tus fondos estén disponibles en la billetera de Futures USDⓈ-M.

✓
No introduzcas manualmente el tamaño de las operaciones

El tamaño será enviado por BTC PRO a WunderTrading cuando se genere una señal válida.

El capital y el objetivo de Take Profit se definen en el Paso 4. No confundas tu saldo con el tamaño nominal de una operación.

6

Conecta y configura WunderTrading

WunderTrading recibe las señales de TradingView y las envía a Binance.

1. Conecta Binance

✓
Abre My Exchanges

En WunderTrading entra a My Exchanges y selecciona Add exchange.

✓
Selecciona Binance

Conecta tu propia cuenta de Binance siguiendo las instrucciones de WunderTrading.

✓
Futures (USDT-M) debe aparecer Active

No continúes hasta que WunderTrading muestre tu cuenta de Futures (USDT-M) como activa.

Nunca compartas contraseñas, frases semilla ni claves privadas. Las API deben utilizar únicamente los permisos necesarios.

2. Crea el Signal Bot

Configuración Valor
Nombre BTC PRO ST V3
Bot start condition TradingView Strategy
Exchange Binance Futures (USDT-M)
Pair BTCUSDT
Leverage 100x
Order Placement Preferences By Value (Leverage-agnostic)
Timeframe 30 Minute
Swing Trade OFF
Max Capital Depende de tu configuración
Max Capital debe ser suficiente para aceptar el tamaño de operación que BTC PRO intenta enviar. No copies el valor de otro usuario.

3. Copia Webhook y JSON

✓
WebHook URL

WunderTrading te mostrará una URL para recibir las alertas de TradingView.

✓
TradingView Strategy JSON

Copia exactamente el JSON generado para tu propio Signal Bot.

No copies el código, Webhook o JSON de otro usuario. Cada Signal Bot genera su propia configuración.

7

Crea la alerta de TradingView

Este último paso conecta BTC PRO con WunderTrading.

✓
Abre BTCUSDT en 30 minutos

Confirma que BTC PRO ST V3 esté cargado en el gráfico.

✓
Crea una alerta

Desde TradingView selecciona Alerta.

✓
Selecciona BTC PRO ST V3

En Condición selecciona la instancia de BTC PRO correspondiente a los parámetros que realmente estás utilizando.

✓
Verifica tu objetivo LIVE

Si modificaste el objetivo de Take Profit, asegúrate de seleccionar la instancia que muestre ese nuevo valor.

✓
Intervalo: 30 minutos

La alerta debe utilizar el mismo timeframe de BTC PRO.

✓
Pega el JSON de WunderTrading

En el campo Mensaje pega exactamente el JSON generado por tu Signal Bot.

✓
Activa URL del webhook

En Notificaciones activa URL del webhook y pega la URL entregada por WunderTrading.

✓
Guarda la alerta

Confirma todos los datos antes de dejar la alerta activa.

Si cambias tu objetivo LIVE después

TradingView puede mostrar más de una instancia de BTC PRO en el menú de Condición.

Ejemplo:

BTC PRO ST V3 (... 400 ...)

BTC PRO ST V3 (... 990 ...)

Debes seleccionar la instancia que corresponda a tu configuración actual antes de guardar la alerta.

Cambiar el objetivo monetario LIVE no significa que debas editar manualmente el JSON de WunderTrading. El JSON recibe dinámicamente la cantidad enviada por la estrategia.
